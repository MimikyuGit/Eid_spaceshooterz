# SpaceShooterz

**SpaceShooterz** es un videojuego 2D de naves desarrollado en Python con Pygame. Integra conceptos de geometría analítica y secciones cónicas (trayectorias lineales, parabólicas y orbitales elípticas) para modelar distintas mecánicas de disparo y habilidades especiales con tiempos de recarga.

## Requisitos
- **Python 3.8+**
- **Pygame** (`pip install pygame`)
- Librerías estándar: `math`, `random`
